# IntelliOps-Lite

Groupe : IntelliOps

Mini-plateforme de supervision d'une chaine DevSecOps : trois agents
(Extraction, Analyse, Notification) qui echangent via un contrat commun
(src/contrat.py).

## Equipe

- Hossam - Etudiant A - Extraction
- Nouhaila- Analyse
- Maroua- Notification

## Verification du TP (etudiant A)

Le [bilan de conformite](docs/CONFORMITE_ETUDIANT_A.md) indique les changements,
les verifications effectuees et les etapes qui attendent les revues de l'equipe.
